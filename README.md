<div align="center">
  <h3 align="center">Allergy Scanner</h3>

  <p align="center">
    Allergy Scanner was built as a student project by a team of four. It is used to scan product barcodes in supermarkets and check if they contain any allergens specified by the user in the app.
  </p>
</div>

---

## 📖 About The Project

In this project I was responsible for creating and connecting the SQLite database to the project, as well as building the allergens panel.
